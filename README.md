# 🎵 Brickify

**A lightweight, Spotify-inspired music player for the R36S and other R36-series handhelds.**

Brickify brings a music-listening experience to your retro handheld, featuring a clean interface, music library browsing, album artwork and playback controls.

Built with **Lua and LÖVE2D 11.5**.

## ✨ Features

- 🎧 Music library browsing
- 💿 Album and artist organization
- ❤️ Liked Songs
- 🔀 Shuffle playback
- 🔁 Repeat modes
- 🖼️ Album artwork support
- 📂 Built-in file manager
- 🎮 Physical button navigation
- 🔊 Volume controls
- ⏩ Track skipping and seeking

## 📥 Installation

1. Download the latest release.
2. Extract the downloaded archive.
3. Copy the Brickify files to your SD card.
4. Insert the SD card into your handheld.
5. Launch Brickify from the Ports menu.

## 🎮 Controls

| Button | Function |
|---|---|
| D-pad | Navigation |
| A | Select / Play / Pause |
| B | Back |
| L1 | Previous track |
| R1 | Next track |
| X | Shuffle |
| Y | Like song |
| START | Open player |
| SELECT | Repeat mode |

## ⚙️ Compatibility

- R36S

Compatibility may vary depending on hardware and firmware.
